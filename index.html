Connexion IA

Branche ton fournisseur pour activer : lecture d'annonce, analyse rédigée, code INSEE. Ta clé reste dans TON navigateur (localStorage), jamais envoyée ailleurs qu'au fournisseur. Pas de crédit API ? Un abonnement Claude/ChatGPT ne donne pas d'accès API. Utilise une offre gratuite : Google Gemini, OpenRouter (modèles :free) ou Groq — même fonctionnement, clé gratuite.
